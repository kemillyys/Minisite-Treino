Política de Privacidade

Clínica Aurora — projeto fictício para fins de treinamento.

Atenção: esta página faz parte de um projeto fictício criado exclusivamente para treinamento em marketing digital. Não devem ser inseridos dados reais de pacientes, clientes ou terceiros.

1. Finalidade deste projeto

A Clínica Aurora é uma marca fictícia utilizada apenas para simular processos de divulgação, geração de leads, atendimento e gestão de relacionamento com clientes.

2. Dados informados em formulários

Eventuais informações preenchidas em formulários de teste devem ser apenas dados fictícios ou dados próprios utilizados voluntariamente para fins de demonstração.

Não devem ser enviados:

  • dados médicos ou informações sobre condições de saúde;
  • diagnósticos, exames ou históricos clínicos;
  • dados pessoais reais de terceiros;
  • qualquer outra informação sensível.

3. Uso das informações

As informações utilizadas neste ambiente de treinamento têm como única finalidade simular etapas de contato, qualificação de leads, agendamento e organização de um funil comercial.

4. Proteção de dados

Em uma operação comercial real, o tratamento de dados pessoais deve observar a legislação aplicável, incluindo a Lei Geral de Proteção de Dados Pessoais (LGPD), bem como informar ao titular, de forma clara, as finalidades do uso de seus dados.

5. Compartilhamento de dados

Este projeto de treinamento não tem como objetivo comercializar, vender ou compartilhar dados pessoais com terceiros.

6. Contato

Como este é um projeto fictício de treinamento, não existe canal oficial de atendimento ao público ou responsável comercial associado a esta página.
